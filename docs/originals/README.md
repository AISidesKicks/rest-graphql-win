# The original sketches

These three images are the source artwork of the lab, the first sketches of the
comparison. They are kept here at full size so they stay available for other uses,
a slide deck or a print.

The site does not serve these files. The web friendly derivatives live in
[`../img/`](../img/), generated by [`scripts/optimize_images.py`](../../scripts/optimize_images.py):

| original | web version |
| -------- | ----------- |
| `rest-vs-graphql.jpeg` (2400x1792, 2.5 MB) | `../img/rest-vs-graphql.jpg` (281 KB) and `.webp` (159 KB) |
| `oltp-vs-olap.jpeg` (2400x1792, 2.3 MB) | `../img/oltp-vs-olap.jpg` (242 KB) and `.webp` (126 KB) |
| `mcp-with-codemode.jpeg` (2400x1792, 2.6 MB) | `../img/mcp-with-codemode.jpg` (326 KB) and `.webp` (187 KB) |

The landing page uses a `<picture>` element, so a browser that speaks WebP downloads
the smaller file and everyone else gets the JPEG.
